# POC 手動功能導覽

這份指南用來熟悉技術POC的功能與操作，不是正式MVP驗收。2026-11-06依人類要求已停止保留的4174網頁服務，本次沒有啟動新服務；既有資料庫與volume保留。

## 之後要操作時再手動啟動

先看功能可以使用暫存模式，不需要Docker或資料庫；資料只保留到程序停止。以下指令由你決定何時執行，代理這輪沒有執行：

```sh
cd /Users/samzhu/workspace_herdr/LaiTse
export PATH="$PWD/.tools/node-v26.13.0-darwin-arm64/bin:$PATH"
npm run build
HOST=127.0.0.1 PORT=4174 DATABASE_URL= HOST_CONTROL_TOKEN= MEETING_ROOM_PASSWORD= LOCAL_CAPACITY_ADMIN=1 npm start
```

這些明確env值讓本次程序使用匿名／暫存模式，覆蓋根.env的同名值，不修改.env、不連既有DB、不清除既有DB內容。終端機保持開啟，結束時按`Ctrl+C`；不會自動在背景常駐。若4174被其他程序占用，不要重複啟動或亂停程序，先確認該服務來源。

Chrome與Edge各開 `http://localhost:4174/?room=studio`，暱稱分別填A、B，按`Join room`。無需帳號。先用兩端看同步；只開一端也能看畫面，但無法確認另一個人是否收到。

## 建議操作順序

| 順序 | 怎麼操作 | 另一端應看到／聽到 |
|---|---|---|
| 1 入場與人物 | A、B各填名字入同一房。點地圖後用方向鍵／WASD移動，也可用畫面的方向按鈕 | 名單有兩人，能看見彼此人物與位置變化；允許同名但仍是不同成員 |
| 2 兩種空間 | 使用Open area／Meeting room選項，或靠近地圖標記門後按Enter、使用門的按鈕 | 未鎖可直接進；進不同房後不顯示對方房內成員／位置。不是走過圖示就一定自動跨房 |
| 3 房內互動 | 在同房點「讚／我想聽／這個實用」，送聊天與固定圖案，再單獨送「公開彈幕」 | 回饋統計和聊天同步；只有明確公開的文字進彈幕，聊天不自動投影；另一房收不到 |
| 4 門與密碼 | A按「上鎖會議室」→填測試密碼→「設定密碼並上鎖」。B先換到Open area，再進Meeting room；試錯密碼後試正確密碼 | 房內B不會因上鎖被踢出；離房後錯密碼不能進，正確密碼才可進。A可改密碼／解鎖，B沒有這些管理操作 |
| 5 管理權 | A在「轉交管理權」找B按「轉交」 | B顯示「你是管理者」，A失去改密碼／解鎖權。換房仍保留owner；只有離線才觸發接任 |
| 6 麥克風 | 都在Meeting room：B先按「開始收聽」，A按「開始麥克風」並允許權限，說話；停止／重新開始，再反方向測 | 對方實際聽見、停止後無新語音、重開可恢復。先單向再雙向，不用量延遲或追求次數 |
| 7 畫面分享 | A按「開始分享畫面」，選其他視窗／分頁；B按「開始觀看分享」。先停麥，再停分享 | B能看見內容；停麥不應停畫面，停分享不應停另一個仍在發布的麥克風。畫面同時只有一人可發布 |
| 8 只互動 | B切「只互動」，再切回「觀看＋互動」 | 只互動仍可聊天／回饋，會停止自己的來源並清除接收；切回後要再手動開始收聽／觀看，不應突然出聲 |

第一次先做到1～4，就能理解空間和會議室；影音可等準備好耳機與分享內容再試。

## 有興趣再補的幾個小流程

- **開放區距離聲音：** A、B都到Open area，A開麥、B收聽；走近應可聽，走遠應停止接收。半徑6格是目前示範值；開放區仍單來源，會議室才是多人可同時開麥且全房接收。畫面分享不依人物距離自動開啟。
- **管理者離線：** 用第三個獨立瀏覽器視窗（例如Chrome無痕）加入C，讓B、C在鎖住的Meeting room內；關閉現任管理者頁面，B/C其中一位接手。只剩管理者在房內時關閉其頁面，無候選則自動解鎖。測真正無回應的網路失聯時，server預設10秒ping／20秒pong期限，可能約20～30秒加處理時間才交接，不是立即。
- **重新整理／晚加入：** 讓一端維持發布，另一端開始收聽／觀看或重新整理；依目前門禁補密碼，等待可解碼畫面。控制／接收可恢復，舊管理或已停止的發布來源不能被自動取回；失敗時先看狀態，勿一直刷新。
- **展示端：** 另開 `http://localhost:4174/?room=studio&view=display`，依畫面加入／密碼提示進入；原房送公開彈幕、回饋，確認展示同步。展示不是一般可開麥／管理的參與者。
- **容量：** 上述暫存啟動指令有開本機容量頁 `http://localhost:4174/poc/capacity`；能看在線數及調整軟限制，原則是拒絕新的加入、不踢掉現有人。不要把可輸入的大數字當已測容量；沒有特別需要可先保留10。

## 音訊與分享的小提醒

戴耳機，避免喇叭聲回到麥克風。單機Chrome／Edge可能用同一支實體麥克風，兩端同時開麥不等於兩個真人交談的品質驗證；先分別測A→B、B→A即可。螢幕分享不要選目前測試頁，避免無限鏡像；macOS若要求麥克風或螢幕錄製權限，由你在系統設定允許。

面板上的收到封包／解碼／PCM計數只是排錯輔助，不能代替你確實聽見／看見。若失敗，記下操作步驟、錯誤文字，以及是「沒聲音」「畫面未出現」或「進不了房」即可，不需做嚴格報告。

## 暫存與PostgreSQL的界線

本頁啟動範例只供看功能，程序停止後設定／聊天等會重置，不能用它驗持久化。要測程序重啟後保留房間設定、聊天與統計，需另用專用PostgreSQL連線設定，操作沿[POC README](README.md)。先前保留的人工PG資料仍在；本輪未重設資料庫，也沒有用暫存結果冒稱PG保存通過。
