# 選用設計與原型檢視

僅在設計產物或原型屬於本次工作時閱讀。預設不要求每個產品都先做 mockup。Figma 是一種選用工具，不是前置條件。

修改前先檢視目前產物、權威需求、交付索引與相關決策。整理使用者目標、進入方式、主要操作、資料來源、範圍和待決問題。畫面只呈現現況，不代表行為已核准或已實作。

每個變更的設計項目，都應在正式產品介面以外記錄用途、進入方式、主要操作、範圍、資料說明、限制與專案定義的穩定識別碼。保留既有識別碼；舊識別碼退役後不可重用。若影響 frames、routes、共用元件主體或父層，先檢查使用情況及相依，再修改。共用節點由單一 writer 寫入，UI 由單一操作者控制。

展示變更設計前，將現況與權威需求／索引同步並讀回確認一致。展示時保留足以理解操作與結果的脈絡。人類確認後，由唯一 writer 記錄原話、日期、ID、範圍與證據；明確區分已收到、排隊／進行中、已保存並讀回。確認紀錄尚待回寫，不阻擋人類明確要求的獨立工作；只有收到指示才切換項目。

沒有設計工具或本次不涉及設計時，依程式庫規格、實作、可執行流程和相關檢查驗收。不要宣稱不存在的展示、互動原型、後端或即時資料連線。
