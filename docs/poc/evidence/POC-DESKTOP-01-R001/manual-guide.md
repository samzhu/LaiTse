# 稍後的單機 Chrome／Edge 人工驗測

入口：**http://localhost:4174/?room=studio**。自動測試的合成來源只注入隔離測試頁，不在應用bundle／服務內；測試頁已關，這個入口用你的普通Chrome／Edge開啟時會走真實擷取與權限流程。這是保留中的本機服務，只可本桌機存取；不需Cloud Run、帳號或憑證安裝。若環境已被停止，由本輪私有runtime重啟，不另開空白memory環境。PostgreSQL資料另存，測試環境不等於商品部署。請保持Docker／OrbStack運作；可能看到自動測試留下的合成暱稱／留言，不是其他真人。

1. 戴耳機。Chrome與Edge各開入口，分別填`Chrome-A`、`Edge-B`並按Join room，確認都在 **Meeting room**。不要用Open area驗多人：開放區目前仍單音訊來源。
2. **先分段驗語音**：Edge按「開始收聽」，Chrome按「開始麥克風」並自行允許麥克風，說一句話；停止Chrome麥克風，確認聲音停止。再反過來Chrome收聽、Edge開麥。兩個方向都能停止／恢復即可，無需量延遲數值。
3. **可選的兩路同時運作**：戴耳機時兩端都開麥／收聽約10秒，各端應只收另一個發布者；停止一端麥克風，另一端仍可發送。兩個瀏覽器可能擷取同一支實體麥克風，因此聲音會重複，不能當真人雙人交談／回音品質測試。
4. **真實畫面分享**：Chrome按「開始分享畫面」，在瀏覽器選擇器選一個有清楚文字的其他視窗；Edge按「開始觀看分享」。確認文字看得見，停止麥克風時畫面仍在，重開麥克風後語音恢復。避免分享目前測試頁造成無限鏡像；macOS若要求麥克風或螢幕錄製權限，由你自行允許，代理不修改系統權限。
5. 在瀏覽器原生的分享提示列按停止分享：接收畫面應停止／清空，語音仍能繼續。需要時再分享一次。最後自行停止所有來源、離開房間。

之後回報「Chrome→Edge聲音／Edge→Chrome聲音／分享與獨立啟停」三項結果即可。只有來源／解碼／PCM數字增加，不能代替你真的聽見。若不正常，保留錯誤文字或下載觀測；不要反覆重開麥克風、提高queue上限或重複刷新掩蓋問題。
