## 本輪操作（約2～3分鐘）

入口：http://localhost:4173/?room=studio 。先用桌機Chrome並戴耳機，開兩個新分頁貼同一網址，不複製已入房分頁。A填「主講」、B填「收聽」，各按Join room。

1. B按「開始收聽」。
2. A按「開始麥克風」，允許瀏覽器使用真實麥克風，說「測試一二三」。
3. 在B應從耳機聽見自己聲音；A按「停止麥克風」後應不再聽到，再開始一次應恢復。
4. B按「停止收聽」後應靜音，再開始收聽應恢復。可選B送一次回饋，A應看到計數。

回報：桌機瀏覽器/版本（知道再填）、是否聽見、A停/重開是否正常、B停/重開是否正常；若失敗，附頁面錯誤文字。真人回報前不填通過。
